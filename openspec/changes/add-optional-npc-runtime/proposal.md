## Why

NewAgent 已具备多会话、长期语义记忆、个人文档 GraphRAG、MCP 和 Skills，但聊天身份仍是单一助手，图谱、记忆与模型能力也主要由系统级配置决定。为支持游戏 NPC、角色扮演和多角色互动，需要在不改变现有默认聊天行为的前提下，引入可选的角色运行时、群聊路由、分层记忆和媒体交互能力。

## What Changes

- 增加用户私有的角色管理：头像、人设、场景、开场白、示例对话、生成参数、工具权限和媒体配置。
- 允许会话保持原有普通助手模式，或绑定单个角色、多个 NPC 与可选的旁白/GM 角色。
- 增加手动指定、@提及、顺序轮询和自动选择等可配置发言路由，并限制单轮参与者和生成轮数。
- 将现有“最近消息 + 语义事实”扩展为短期上下文、滚动摘要、情节记忆、角色私有记忆和共享场景状态。
- 在文档上传时提供可选图谱构建模式，并在会话中分别控制向量检索与图谱检索；未启用或失败时可降级到现有向量 RAG。
- 增加可插拔图片生成和 TTS Provider 接口、角色级媒体配置及消息附件；未配置 Provider 时保持纯文本交互。
- 所有新增能力默认关闭或沿用系统现状，现有用户、会话、文档和 API 客户端无需迁移即可继续使用。

## Capabilities

### New Capabilities

- `character-management`: 用户创建、编辑、复制、删除和选择私有 NPC 角色及其人设、权限和默认生成配置。
- `npc-group-orchestration`: 会话成员、单角色/群组模式、NPC 发言选择、顺序执行和可观察的路由结果。
- `layered-npc-memory`: 面向长对话的滚动摘要、情节事实、角色私有记忆、共享场景状态及可控压缩。
- `document-graph-controls`: 上传时图谱索引选择、后续构建/重建和会话级向量/图谱检索策略。
- `optional-media-interaction`: 可插拔图片生成与 TTS、角色级声音/外观配置、消息附件和纯文本降级。

### Modified Capabilities

- `conversation-management`: 会话可选择普通助手、单 NPC 或多 NPC 模式，并管理会话成员与运行时设置。
- `chat-core`: 发送和流式响应需要携带说话角色、路由事件、附件及按角色构建的上下文，同时保持旧请求兼容。
- `chat-memory`: 现有语义事实记忆需要支持角色/共享作用域、摘要检查点和失效替代关系。

## Impact

- PostgreSQL：新增角色、会话成员、摘要/场景状态、Provider 配置和消息附件等表，并扩展会话、消息、文档和记忆字段。
- FastAPI：增加角色、编排、图谱操作、媒体 Provider 与附件 API；扩展聊天流事件和文档上传参数。
- 聊天服务：从固定单助手流程拆出角色上下文组装、路由选择、逐角色生成、记忆压缩和媒体后处理。
- Qdrant/Neo4j：增加角色与作用域过滤；图谱索引继续异步、可重试并允许按文档跳过或补建。
- Vue 前端：增加角色管理、会话成员/模式、记忆设置、文档图谱开关、图片与语音控件。
- 配置与安全：增加可选 Provider 配置、能力探测、调用限额和密钥保护；未配置外部服务时不影响核心聊天。
